# SubscriptionManager.Domain

The Domain project contains the core business concepts and rules of Subscription Manager.

## Domain Areas

| Area            | Responsibility                                                                                |
|-----------------|-----------------------------------------------------------------------------------------------|
| Billing         | Defines Subscription Manager plans, billing subscriptions, statuses, and plan change rules.   |
| DigitalServices | Defines digital services associated with user subscriptions.                                  |
| ExchangeRates   | Defines exchange rates used to convert subscription costs between supported currencies.       |
| SavingsPlans    | Defines savings plan concepts used to reduce subscription costs.                              |
| Subscriptions   | Defines user subscriptions, billing periods, currencies, and recurring cost calculations.     |
